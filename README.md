# 🌥️ Cidadão Cloud

## Sobre o projeto

O **Cidadão Cloud** é uma aplicação desenvolvida com o objetivo de aproximar a população dos serviços públicos, tornando mais simples o processo de registrar problemas encontrados nas cidades.

A proposta surgiu da dificuldade que muitos cidadãos enfrentam para identificar qual órgão é responsável por resolver determinados problemas urbanos, como:

* 🕳️ Buracos nas vias;
* 💡 Postes ou iluminação pública com defeito;
* 🚰 Vazamentos ou canos estourados;
* 🗑️ Acúmulo de lixo e entulho;
* 🌳 Outros problemas de infraestrutura urbana.

Em muitos casos, a população deixa de realizar a denúncia por não saber para onde encaminhar a solicitação ou por considerar o processo burocrático.

O **Cidadão Cloud** busca reduzir essa barreira utilizando Inteligência Artificial para identificar automaticamente o tipo de problema a partir de uma fotografia enviada pelo usuário, permitindo que a ocorrência seja direcionada ao órgão público competente.

## Objetivo

O principal objetivo do projeto é facilitar a comunicação entre cidadãos e órgãos públicos, tornando o processo de denúncia mais rápido, intuitivo e acessível.

Além disso, o sistema pretende:

* Automatizar a identificação do problema através de visão computacional;
* Reduzir erros na classificação das ocorrências;
* Incentivar a participação da população na melhoria das cidades;
* Contribuir para uma gestão pública mais eficiente.

## Como funciona

De forma simplificada, o fluxo da aplicação é:

1. O usuário envia uma foto do problema encontrado.
2. A Inteligência Artificial analisa a imagem e identifica sua categoria.
3. O sistema determina qual órgão público é responsável.
4. A ocorrência é registrada e encaminhada para o setor correspondente.

## Tecnologias

Este repositório contém o **Frontend** da aplicação.

Entre as principais tecnologias utilizadas estão:

* React
* Vite
* TypeScript
* Tailwind CSS

## Projeto acadêmico

O Cidadão Cloud foi desenvolvido como um projeto acadêmico, buscando aplicar conceitos de desenvolvimento web, integração entre frontend e backend e utilização de Inteligência Artificial para solucionar um problema real enfrentado pela população.
